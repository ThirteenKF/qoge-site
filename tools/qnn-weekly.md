## 1. Что это
- Еженедельный дайджест в Telegram-канале https://t.me/QOGEofficial (мемкоин $QOGE, сеть Quai Network,
  сайт https://www.qoge.fun). Язык выпуска — русский. Плюс короткий английский тред для X.
- Выходит по понедельникам, охватывает последние 7 дней.
- Claude только готовит текст. Публикует владелец: присылает текст боту в личку → бот делает черновик
  с кнопкой «✅ Опубликовать» → после публикации бот сам кладёт выпуск в архив.

## 2. Память: прочитай прошлые выпуски
Перед исследованием — WebFetch:
https://www.qoge.fun/api/telegram?action=issues&limit=4
(JSON `{issues:[{n, date, title, t}]}`, новые первыми; архив для людей — https://www.qoge.fun/weekly).
Из прошлых выпусков возьми:
- **номер**: новый выпуск = последний `n` + 1 (если архив пуст — #1);
- **прошлый слух** и его вердикт → в этом выпуске одна строка «Слух прошлой недели: подтвердился / нет / пока неясно»
  (проверь заново поиском);
- **прошлый призыв** → выбери следующий по кругу: ресёрч → опрос «какой проект разобрать» → минт Mars Gum → ресёрч…;
- **не повторяй** новости, которые уже были, если у них нет нового развития.
Если адрес недоступен — делай выпуск без этих строк и напиши владельцу, что архив не прочитался.

## 3. Исследование (WebSearch, отдельный запрос на каждый пункт, параллельно)
1. Значимые мировые новости недели: ИИ, IT, крипта.
   Фильтр «значимо» = влияет на деньги / технологии / регулирование. Ценовой шум — не новость.
2. Список наблюдения — по каждому проекту отдельный поиск за неделю:
   QUAI, INJ, STRK, NEAR, QRL/QTC, AVAX, ICP, ALGO, ZEC, LINK, DASH, ATOM, KSM, DOT, LTC.
   Только реальные события: апгрейды, листинги/делистинги, ETF, подтверждённые партнёрства,
   регуляторика, взломы, разлоки.
3. Слух недели: один громкий слух по крипте или списку наблюдения, проверенный по первоисточникам.
4. Цифра недели: одно число недели, которое объясняет главное (притоки в ETF, сумма взлома, рост сети…).
5. Календарь на следующие 7 дней: 2–3 даты (апгрейды, разлоки, решения по ETF, голосования).
6. $QOGE: WebFetch https://www.qoge.fun/api/metrics — market cap, цена, ликвидность, холдеры, изменения.
   Этапы роадмапа: 500 / 1000 / 2500 / 5000 холдеров — посчитай, сколько осталось до ближайшего.
   Mars Gum (NFT, минт для холдеров, 99 QUAI): https://launchpad.bazarr.xyz/mint/0x003880cbfaeb5050edbb61dcc4f8fd226826f4d8
   Ресёрч: https://www.qoge.fun/research/
7. Quai из нашего дашборда: WebFetch https://www.qoge.fun/api/quai (JSON; попроси вытащить именно эти поля):
   - `soap.last7`, `soap.last30`, `soap.prev30` — выручка выкупа SOAP, $ (за 7 дней, 30 дней и 30 дней до этого);
   - `recon.last30.burnedUsd` / `recon.last30.revenue` — сколько выручки ушло на сжигание за 30 дней;
   - `supply.d30.coverage` — покрытие выкупом: доля новых QUAI за 30 дней, которую сжёг SOAP;
   - `supply.unlocks.next` — ближайший разлок генезиса (`t` = unix-время, `quai` = сколько);
   - `market.depthUp` — сколько $ стоит в стаканах бирж в пределах +2% (ликвидность);
   - `health` и `cached` — если там есть строки про сбой/кэш, бери только свежие поля и не выдавай старое за новое.
   Если адрес не открылся — блок без этих цифр и пометка владельцу.

## 4. Структура (строго в этом порядке)
```
QNN Weekly #N · <даты недели>

⚡ Главное за неделю — 3 строки (в насыщенную неделю до 5, тогда остальное сокращай)
🐕 $QOGE: N холдеров, до этапа осталось X

🔢 Цифра недели — число + одна строка, что оно значит

🌍 Мир: ИИ / IT / крипта — 2–3 пункта, «факт → что это значит»

👀 Список наблюдения — 2–3 пункта, «Проект: факт → что это значит»

🔎 Слух недели
«Что говорят» → что проверили → что это значит
Вердикт: ✅ правда · ⚠️ правда, но… · ❓ не подтверждено · ❌ фейк · 🕰 уже случилось
Слух прошлой недели: … (из архива)

📌 Ещё за неделю — 4–5 строк по 5–7 слов, без объяснений

🐕 $QOGE / Quai — метрики, Mars Gum, новости сайта
   + 1–2 строки из дашборда (п.3.7): выручка SOAP за неделю и к прошлому месяцу, покрытие выкупом, ближайший разлок,
   и ссылка [Дашборд QUAI](https://www.qoge.fun/research/quai-live/). Если неделя по Quai спокойная, хватит одной строки.

📅 Календарь на 7 дней — 2–3 даты

👉 Один призыв к действию (по кругу, см. п.2)

[qoge.fun](https://www.qoge.fun) · [Архив](https://www.qoge.fun/weekly) · [X](https://x.com/QOGEofficial) · [Telegram](https://t.me/QOGEofficial)
```
Первая строка обязательно начинается с `QNN Weekly #N` — по ней бот нумерует архив.

## 5. Правила
- Каждый пункт = новый факт, новый вывод или призыв; максимум 2 строки.
- Основных пунктов (мир + список наблюдения + слух) 6–8. Важное, не влезшее в «Главное», — в свои блоки или в 📌.
- Порядок везде — по силе влияния на деньги / технологии / регулирование.
- Никаких «покупай / продавай», никаких своих прогнозов цены.
- Цифры Quai из дашборда — это наш собственный расчёт по открытым данным: пиши «по нашему дашборду»,
  без оценок команды и без «выкуп провалился». Покрытие выкупом и «доля выручки на сжигание» — разные числа, не путай.
- Слухи — только уже обсуждаемые, со ссылкой на источник и на подтверждение/опровержение.
  Слухи про $QOGE / Quai — только вместе с ответом команды.
- Каждый факт подтверди найденным источником; не подтвердился — не включай.
- Разметка только `**жирный**` и `[текст](url)`. Без заголовков `#`, без таблиц.
- **Жёсткий лимит: не больше 3900 символов** (бот отклоняет > 4096). Посчитай длину кодом.

## 6. Английский тред для X
4–5 постов, каждый ≤ 270 символов, на английском: 1) хук + главное; 2) цифра недели; 3) слух недели с вердиктом;
4) $QOGE (холдеры, до этапа) + одна цифра Quai из дашборда со ссылкой https://www.qoge.fun/research/quai-live/; 5) ссылка на архив https://www.qoge.fun/weekly и Telegram.
Без «buy/sell», хэштеги максимум 2 на весь тред ($QOGE, #Quai).

## 7. Что отдать владельцу
1. Русский выпуск — целиком одним блоком, готовым к копированию (через SendUserMessage, если запуск по расписанию).
2. Английский тред — пронумерованные посты.
3. Коротко: источники по пунктам и длина русского текста в символах.
Ничего не публиковать самому.

## 8. Техника (для разработчика)
- `api/telegram.mjs`: черновики, публикация, архив (Redis `tg:issues`, `tg:issue_no`), `GET ?action=issues`.
- `api/weekly.mjs`: HTML-архив `/weekly`, `/weekly/N` (rewrites в `vercel.json`).
- Отправка черновика напрямую: `POST /api/telegram?action=draft`, заголовок `Authorization: Bearer <DIGEST_SECRET>`,
  тело `{text, image?, title?}`. Секрет только в Vercel env, никогда в репозитории и не в промптах.
